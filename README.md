
Recruitment & Placement Management System (RPMS)

📌 Project Overview

The Recruitment & Placement Management System (RPMS) is an internship project designed to simplify and manage recruitment and placement activities.

The system aims to manage candidate information, company details, job opportunities, applications, interviews, and placement-related activities through a centralized platform.

🎯 Objectives

- Manage candidate records.
- Maintain company information.
- Manage job opportunities.
- Track candidate applications.
- Organize interview details.
- Support placement management activities.
- Store and retrieve information using a database.

⚙️ Current Features

- Database connection using JDBC.
- Candidate records retrieval from MariaDB.
- Candidate data displayed through the Candidates page.
- Java HTTP server for API communication.
- GET API for retrieving candidate information.
- POST API for candidate registration.

🗄️ Database

Database name: "rpms_db"

The database contains 17 tables related to users, candidates, companies, jobs, applications, interviews, skills, placements, and other recruitment activities.
